---

I need you to help me set up Vapi.ai for my AI voice automation business. I am NOT technical, so please give me extremely simple, step-by-step instructions like you're explaining to a 10-year-old.

## WHAT I NEED:
1. A working AI voice agent that can answer phone calls
2. Something real I can show to clients (not a demo)
3. The setup should be free or very low cost
4. I need this working TODAY

## MY BUSINESS:
- I sell AI automation services to businesses (HVAC, dental, real estate, etc.)
- I need to show clients that AI voice agents actually work
- I have zero budget, so need the free tier

## PLEASE GIVE ME:
1. Step-by-step account setup (click here, then click there, etc.)
2. How to create a voice agent (what to type in each field)
3. How to get a phone number connected
4. How to test that it actually works
5. A sample script the AI should say when answering calls

## IMPORTANT:
- Make each step extremely specific (don't say "configure settings" - say "click the button that says 'Settings' in the top right corner")
- Include what I should type in each text field
- Tell me exactly what to click next
- If there are multiple options, tell me which one to choose
- Assume I know nothing about technology

## SAMPLE SCRIPT FOR THE AI:
When the AI answers, it should say something like:
"Hi, thanks for calling [Business Name]. This is an AI assistant. How can I help you today?"
It should be able to:
- Take messages
- Answer basic questions like hours and location

- Transfer to a human if needed

Please walk me through the entire setup process from start to finish, including testing that it actually works.
